# Error Log

Registra només errors que valgui la pena no repetir.

| Date | Subject | Error | Type | Cause | Correct rule / fix | Re-test |
|---|---|---|---|---|---|---|

## Types

- `K` — Knowledge: no ho sabia.
- `R` — Recognition: sabia la teoria però no vaig veure el patró.
- `E` — Execution: sabia què fer però ho vaig implementar/calcular malament.
- `T` — Time: massa lent.
- `C` — Careless: error evitable.

## Rule

Un error important no es considera tancat fins que s'ha superat almenys un re-test sense ajuda.
